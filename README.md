# قائمتي الذكية - PWA

تطبيق قائمة مشتريات عربي بتصميم احترافي يعمل على iPhone عبر Safari و GitHub Pages.

## طريقة الرفع
1. ارفع الملفات في مستودع GitHub.
2. من Settings > Pages اختر branch: main و root.
3. افتح الرابط من Safari على الآيفون.
4. اختر مشاركة > إضافة إلى الشاشة الرئيسية.

## المزايا
إضافة وتعديل وحذف، تحديد تم الشراء، بحث وفلترة، إجمالي ونسبة إنجاز، مشاركة واتساب، تصدير واستيراد JSON، وعمل أوفلاين.
